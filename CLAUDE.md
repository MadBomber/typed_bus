## Overview

TypedBus is a Ruby gem providing an async pub/sub message bus with typed channels, ACK-based delivery, and dead letter queues. Built on the `async` gem with fiber-only concurrency — no mutexes, no threads. All state lives within a single Async reactor.

## Commands

```bash
# Run full test suite (Minitest)
bundle exec rake test

# Run a single test file
bundle exec ruby -Itest test/typed_bus/channel_test.rb

# Run a single test method
bundle exec ruby -Itest test/typed_bus/channel_test.rb -n test_method_name

# Run examples (each is standalone, requires Async reactor)
bundle exec ruby examples/01_basic_usage.rb

# Build the gem
bundle exec rake build

# Install locally
bundle exec rake install
```

Coverage reports are generated by SimpleCov (with branch coverage) into `coverage/`.

## Architecture

```
MessageBus (registry facade, shared Stats)
  └── Channel (named, optionally typed pub/sub topic)
        ├── Delivery (per-subscriber envelope, wraps message, has ack!/nack! + timeout)
        ├── DeliveryTracker (aggregates N subscriber responses per publish)
        └── DeadLetterQueue (collects nacked/timed-out deliveries)
```

**Publish flow:** `MessageBus#publish` → `Channel#publish` → type check → throttle delay → backpressure wait → fan-out to subscribers as `Delivery` envelopes → tracked by `DeliveryTracker` → on nack/timeout → `DeadLetterQueue`.

**Key design decisions:**
- Subscribers must explicitly `ack!` or `nack!` each Delivery; unresolved deliveries auto-nack after timeout
- Messages published with no subscribers go directly to the DLQ
- Backpressure (`max_pending`) blocks the publishing fiber via `Async::Condition`
- Adaptive throttle (`throttle: Float`) applies asymptotic delay as capacity fills
- Stats are per-channel counters: `#{channel_name}_published`, `_delivered`, `_nacked`, `_timed_out`, `_dead_lettered`, `_throttled`
- All logging is optional via `TypedBus.logger` (standard Ruby Logger)

## Test Structure

Tests use Minitest. Many tests require `Async { }` blocks since Channel and Delivery create Async tasks internally (timeouts, subscriber dispatch). The test helper at `test/test_helper.rb` configures SimpleCov and requires `typed_bus`.
